

# Attention pour la Configuration des fichiers pour les tests 

- Le fichier `server.js` peut être placé n'importe où sur le système.
- Le fichier `index.html` doit être placé dans le répertoire racine du serveur web.

**Exemple avec Apache sur une machine virtuelle :**
Dans mon cas, j’ai placé `index.html` dans `/var/www/html/` à la place de l'autre.
